Turn 02 · Cold Steel, one layout for both

Responsive shell

You're right: with 39% desktop, a bottom bar as the primary nav wastes the widest screens. So the nav is one set of destinations rendered two ways — a horizontal tab bar in the top chrome from 900px up, the same five items as a bottom bar below it. Everything else follows one rule: desktop puts panes side by side, mobile stacks them and pushes the detail pane to its own view. Palette and type are 1a exactly. The phone screens from 1a stay below as the mobile end of this same system.

2a
Cold Steel · desktop 1440 → phone 390
≥ 1200 · THREE PANE
Filters · list · detail all visible. Nothing opens as a modal.
900–1200 · TWO PANE
Filters collapse to a chip row above the list.
< 900 · STACKED
Detail becomes its own view. Bottom bar appears only here.
WHY IT HOLDS
Every screen below is the same three regions: scope (what am I filtering), sequence (the list), subject (the one thing I'm working on). Desktop shows all three; phone shows one at a time. No layout is invented per breakpoint, so a change lands everywhere.
