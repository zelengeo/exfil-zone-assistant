DESCRIPTIVE · NOT RANKED
The band is a quartile against the 74 shipped presets whose receiver carries a GunType.Rifle.* tag — same class only, so an SMG's ergonomics never sets the bar for a rifle's. It moves as you fit parts, because it is computed from the assembled number, not the preset's.
The delta beside the value and the band under it answer different questions: the delta is "what did my last part do", the band is "is this gun any good". The stock AK-74N is the case for having both — top-half recoil on bottom-quartile ergonomics.
